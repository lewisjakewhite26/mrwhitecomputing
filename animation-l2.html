Words for today

frame

One picture in an animation. Each page of a flipbook is one frame.

sequence

Things in the right order. Frame 1, then frame 2, then frame 3.

consistent

Kept the same every time, like the size of the ball and where the ground is.

Year 4Ball C wasn’t consistent. What changed when it shouldn’t have?Its size and the ground

How to make yours smooth

Trace at the windowHold the new page over the last one, up to a bright window
Keep it the sameSame size, same ground, only move what moves
Small gap, slow. Big gap, fastA falling ball gets faster, so the gaps get bigger
Squash and stretchStretch it when it’s fast, squash it when it lands
Number your pagesSo they never get muddled
It doesn’t have to be perfectTry it, flick it, have fun with it
