01

Technology in our classroom

76→80
Before

10 slides, few reveal cards. Already had a checked Technology / Not Technology sort.

What got built

Pupils photograph technology round the room in pairs, using the iPad's own Camera app, then sort what they found as a class. Real device use, though the sort stays a discussion rather than a checked slide.

02

Using computer technology

34→88
Before

11 slides, 8 reveal cards. The real activity lived off-site on code.org.

What got built

Rebuilt twice. The peripheral-devices sort stayed (Screen dropped, ambiguous on a touchscreen; icons enlarged for Y1/2 hands). The click-and-drag demo now leads into a real image-slice jigsaw, checked, with an optional 3x3 harder version. Added a fake power-on/login mockup and a second checked sort ("Inside or outside?") replacing a Quick-Click-only slide. 02

What parts make up a digital device?

70→81
Before

11 slides, 3 reveal cards, already had a checked sort. Design-your-own-device task was unstructured.

What got built

A 3-tick peer-checked rubric for the design task: has an input, has an output, does the process make sense. Second pass: "Spot the devices" turned from a static tap-to-reveal answer card into a real click-in-the-story activity, tap each device, locks green if right, shakes if it's a decoy like "alarm" or "car".
